# RAG-Based Resume–Job Description Matching Assistant 🚀

An AI-powered application that compares a resume with a job description to identify matching skills and skill gaps.

## Features

* Extracts text from resume and job description PDFs.
* Identifies required and preferred skills.
* Uses semantic search to find relevant resume evidence.
* Classifies skills as Strong Match, Partial Match, or Missing.
* Calculates an overall skill match score.
* Displays results using a Streamlit interface.

## Tech Stack

* Python
* Streamlit
* Sentence Transformers
* FAISS
* Gemini API
* PyPDF
* python-dotenv

## Learning Outcomes

Explored text embeddings, semantic search, vector databases, RAG workflows, LLM integration, and Streamlit application development.
